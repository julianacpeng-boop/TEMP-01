# TEMP-01 — Laboratório virtual

Protótipo funcional paramétrico do analisador de temperatura. Não é simulação SPICE nem calibração certificada.

Abra index.html no navegador. Para publicar, habilite GitHub Pages na branch main, pasta raiz.

Os valores de resistência devem ser fornecidos conforme o circuito original. Pendentes: esquema elétrico, firmware, modelos SPICE, CAD e validação experimental.
